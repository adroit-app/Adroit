# Console themes

The colour themes adroit offers for its console, in Ghostty's theme format:
`palette = N=#rrggbb` for the sixteen colours, then `background`,
`foreground` and `cursor-color`.

Each is the colour lines of a theme made for Vim or Neovim, taken from where
the table says. Most come from the
[iTerm2 Color Schemes](https://github.com/mbadolato/iTerm2-Color-Schemes)
collection, which Ghostty's themes are made from; its MIT licence
(`iTerm2-Color-Schemes`) covers the collection, and each theme stays under its own authors' licence. A theme is
taken only when its own licence lets it be copied and shipped, as the
collection's `licenses.yml` and the theme's own repository both record it.
The licence texts are in `LICENSES/`.
